# Sip & Chill – Responsive Milkshake Platform & E-Commerce Ordering

## Project Overview
This is a modern, responsive milkshake brand platform and e-commerce ordering interface designed for Sip & Chill, based in Midrand. The project demonstrates advanced frontend layout curation, interactive menu card arrays, and live product checkout state handling.

## Technical Stack
* **Core Design Engine:** HTML5 Semantics, Vanilla CSS3 (Global Brand CSS Custom Properties)
* **Layout Alignment Architecture:** Responsive CSS Flexbox, Multi-Column CSS Grid
* **Interactivity & Cart Logic:** Vanilla JavaScript (ES6+) DOM Event Handlers

## Key Technical Features
* **Interactive Menu & E-Commerce Ordering:** Features a transactional product menu display layout showcasing signature milkshakes (Peppermint, Chocolate, Caramel, Raspberry, Strawberry) with responsive styling triggers.
* **Frosted Glass UI Components:** Design components are engineered with modern glassmorphism principles using backdrop blur properties, scale transitions, and high-contrast text layouts to maximize visual impact.
* **Frontend Shopping Cart Mechanics:** Integrated custom script modules to handle live milkshake configuration states—managing interactive item quantity increments, toast success indicators, and direct floating access points.
* **Vertical Media Carousel Track:** Features an isolated vertical viewport carousel animation engineered with explicit flex-shrink constraints to cycle high-resolution drink graphics smoothly.
